# Changelog

## 1.0.0

Tagged as `v1.0.0`. The AppImage, the `.deb`, and the `.rpm` are on that GitHub release.

This version is remote play and cloud gaming in a window. A real controller is passed through on its own. Keyboard and mouse are one Xbox pad, with the Greenlight key table, and F3 can force the keyboard even when a pad is plugged in. The stream shows delay and bitrate, reconnects if it drops, and stays up when you step away.
