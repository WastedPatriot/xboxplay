# Changelog

## Unreleased

Closing the app ends the console session, and the next open clears the xbox.com site cache, so remote play is not black after a reopen. Clicking away keeps the page visible and focused so the picture does not pause. A second launch brings the open window forward. A picture that sits still for a few seconds is resumed. Coming back to the window puts the real controller back in front of the keyboard pad. F4 does the same thing by hand. Leaving fullscreen during a stream no longer leaves the fullscreen warning stuck on screen. Clicks and the controller still work on an xCloud dialog.

## 1.0.0

Tagged as `v1.0.0`. The AppImage, the `.deb`, and the `.rpm` are on that GitHub release.

This version is remote play and cloud gaming in a window. A real controller is passed through on its own. Keyboard and mouse are one Xbox pad, with the Greenlight key table, and F3 can force the keyboard even when a pad is plugged in. The stream shows delay and bitrate, reconnects if it drops, and stays up when you step away.
